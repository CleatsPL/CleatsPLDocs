# ECHO/01

React + Vite rebuild of the ECHO/01 ambient intelligence landing page.

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (default `http://localhost:5173`).

## Structure

```
src/
  App.jsx
  styles.css
  hooks/useEchoMotion.js   # GSAP + ScrollTrigger
  components/              # page sections
public/assets/             # photography
```

The original single-file replica is kept under `CleatsPLDocs/echo-replica/` for reference.
